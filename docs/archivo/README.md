# Archivo

Toda la documentación de SociAI hasta el 2026-10-20. Ese día se archivó completa para empezar en limpio sobre la arquitectura nueva. **El código no cambió:** se trabaja sobre él con documentación nueva.

**No se consulta en el trabajo diario.** Se abre solo para un caso específico, por ejemplo, para saber por qué el código hace algo de cierta forma. Nada de aquí se edita; lo que siga valiendo se escribe de nuevo en `docs/`.

| Carpeta | Qué guarda |
|---|---|
| [`adr/`](adr/README.md) | Los ADR 001 a 048 y su índice |
| `documentos/` | Visión, arquitectura, gobernanza, escáner, modelo de datos, IA y costos, estilo de redacción, roadmap, sistema visual, guiones de prueba y el mapa del proyecto (00 a 16) |
| `agents/` | Las instrucciones para los agentes de desarrollo: principios, glosario, comandos y pruebas, flujo de trabajo, roles, patrones de IA y metodología de los Lectores |
| `tablero/` | El tablero Kanban y sus bloques (ERP-1 a ERP-4, IA-1 a IA-9) |
| `notas/` | Las observaciones de la persona dueña del proyecto |
| `plantillas/` | Las plantillas de bloque y de observación |
| `codigo-archivado/`, `prompts-archivados/` | Código y oficios que salieron del programa |

`docs/manual/` no se archivó: el programa lo compila dentro de la app (el manual y el mapa de lugares, `core/manual` y `core/places.rs`).
